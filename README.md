# DopAvto — сайт мастера по установке автоэлектроники

Одностраничный сайт для мастера из Дзержинского (г. о. Люберцы): установка Android-магнитол, камер заднего вида и 360°,
парктроников, автозвука, подсветки салона, видеорегистраторов, электропривода багажника, противотуманных фар.

Главное на сайте — интерактивная 3D-машина: её можно крутить и приближать, а при выборе услуги
камера переезжает к нужному месту и показывает, что изменится после установки.

## Как запустить

Сайт статический, сборка не нужна. Из-за 3D-модели его нужно открывать через локальный сервер, а не двойным щелчком:

```
python -m http.server 8000
```

и открыть http://localhost:8000/

Подойдёт любой статический хостинг (GitHub Pages, Cloudflare Pages, обычный хостинг).
Форма заявки без серверного обработчика работает в демо-режиме: заявка сохраняется только в браузере.

## Что где

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | страница и оформление |
| `services.js` | список услуг: тексты, ракурсы камеры |
| `page.js` | выбор услуги, форма заявки, просмотр фото, анимации при прокрутке |
| `car.js` | 3D-сцена (three.js): машина, материалы, узлы услуг, эффекты |
| `carconcept-draco.glb` | 3D-модель машины, сжатая: геометрия Draco, текстуры WebP (2 МБ вместо 11,8) |
| `img/` | фото работ мастера |
| `logo.svg` | логотип |
